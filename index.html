Политика конфиденциальности приложения «ЯсноЛайф»

Дата вступления в силу: 22 сентября 2026 года

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает мобильное приложение «ЯсноЛайф», для каких целей они используются, где хранятся и каким образом пользователь может удалить свои данные.

2. Назначение приложения

«ЯсноЛайф» — персональный цифровой журнал для хранения информации о здоровье, теле, питании и образе жизни пользователя.

Приложение позволяет пользователю самостоятельно создавать и хранить записи, включая сведения о весе, шагах, питании, целях, заметках, измерениях и фотографиях.

Приложение не является медицинским изделием и не предназначено для постановки диагнозов, лечения или предоставления медицинских рекомендаций.

3. Данные, хранящиеся на устройстве

Основные данные журнала хранятся локально на устройстве пользователя.

К таким данным могут относиться:

  • вес и другие измерения тела;
  • сведения о шагах и активности;
  • записи о питании;
  • калорийность и масса продуктов и приёмов пищи;
  • фотографии тела и еды;
  • заметки пользователя;
  • цели;
  • данные профиля;
  • настройки приложения.

Эти данные не передаются разработчику и не загружаются приложением на удалённый сервер.

Удаление приложения или очистка его данных средствами операционной системы Android может привести к удалению локально сохранённой информации.

4. Резервные копии

Пользователь может самостоятельно создать резервную копию данных средствами приложения.

Резервная копия создаётся только по инициативе пользователя и сохраняется в место, выбранное самим пользователем.

«ЯсноЛайф» не выполняет автоматическую отправку резервных копий на сервер разработчика.

Если пользователь самостоятельно сохраняет резервную копию в облачное хранилище или другое стороннее приложение, дальнейшая обработка файла определяется условиями соответствующего сервиса.

5. Обратная связь

Для работы раздела «Обратная связь» приложение использует подключение к Интернету.

При использовании функции обратной связи могут обрабатываться:

  • имя, указанное пользователем;
  • адрес электронной почты;
  • случайный технический идентификатор установки приложения;
  • текст сообщений пользователя;
  • ответы разработчика;
  • служебные данные, необходимые для подтверждения электронной почты и доступа к переписке.

Эти данные передаются только в случае, если пользователь самостоятельно использует функцию обратной связи.

Для технической обработки и хранения данных обратной связи используются сервисы Google, включая Google Apps Script и Google Sheets.

Данные обратной связи не используются для рекламы, рекламного профилирования или продажи третьим лицам.

6. Подтверждение электронной почты

Для подтверждения адреса электронной почты приложение отправляет пользователю проверочный код.

Проверочный код имеет ограниченный срок действия. Служебные данные авторизации используются исключительно для защиты доступа к переписке пользователя.

7. Удаление данных обратной связи

Пользователь может удалить данные обратной связи непосредственно из приложения «ЯсноЛайф».

При подтверждении удаления удаляются связанные с системой обратной связи данные пользователя, включая:

  • имя;
  • адрес электронной почты;
  • технический идентификатор;
  • сообщения пользователя;
  • ответы разработчика;
  • служебные данные доступа.

Удаление данных обратной связи не удаляет локальный журнал «ЯсноЛайф», фотографии, записи о питании, весе и другие данные, находящиеся только на устройстве пользователя.

8. Передача данных третьим лицам

Разработчик не продаёт персональные данные пользователей.

Данные могут обрабатываться сторонними техническими сервисами только в объёме, необходимом для работы соответствующей функции приложения.

В настоящий момент для функции обратной связи используется инфраструктура Google.

Данные также могут быть предоставлены в случаях, предусмотренных применимым законодательством.

9. Реклама и аналитика

В текущей версии приложения «ЯсноЛайф»:

  • отсутствует сторонняя реклама;
  • не используются рекламные идентификаторы;
  • отсутствуют сторонние системы аналитики поведения пользователей;
  • данные журнала не используются для рекламного профилирования.

10. Доступ к Интернету

Приложение использует доступ к Интернету для работы функции обратной связи.

Основные функции персонального журнала и локальные пользовательские данные не требуют передачи этих данных разработчику.

11. Срок хранения данных

Локальные данные журнала хранятся на устройстве до их удаления пользователем, очистки данных приложения или удаления самого приложения.

Данные обратной связи хранятся до момента их удаления пользователем через предусмотренную в приложении функцию либо до прекращения работы соответствующего сервиса.

12. Защита данных

Разработчик принимает разумные технические меры для ограничения несанкционированного доступа к данным.

Для доступа к переписке обратной связи используется подтверждение электронной почты и индивидуальные служебные данные авторизации.

Передача сетевых запросов осуществляется через защищённое соединение HTTPS.

13. Управление своими данными

Пользователь может:

  • просматривать и изменять данные, сохранённые в приложении;
  • удалять отдельные локальные записи;
  • удалить локальные данные путём очистки данных приложения или его удаления;
  • создавать резервную копию своих данных;
  • удалить данные системы обратной связи;
  • обратиться к разработчику по вопросам обработки своих данных.

14. Изменения Политики

Настоящая Политика может обновляться при изменении функций приложения, способов обработки данных или требований законодательства и магазинов приложений.

Актуальная редакция Политики публикуется на этой странице.
